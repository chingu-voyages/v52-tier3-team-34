### Key Testing Utilities
- `ApiClient`: Wrapper for making HTTP requests with proper configuration
- `testData`: Utilities for managing test data and cleanup
- `environment`: Handles test environment configuration
- `config`: Contains API endpoints and test settings

### Test Patterns
```typescript
// Example test structure from venues.test.ts
describe('Venues API', () => {
    let createdVenueId: number;
    let testUser: User;

    beforeAll(async () => {
        await validateTestData();
        testUser = await getTestUser();
    });

    describe('GET /venues/:id', () => {
        it('should return venue with includes', async () => {
            const response = await api.get<VenueResponse>(`${endpoint}/${id}?include=events,user`);
            expect(response.status).toBe(200);
            expect(response.data.data).toHaveProperty('events');
            expect(response.data.data).toHaveProperty('user');
        });
    });
});
```

### Environment Setup

- Each test file can specify environment-specific test data
